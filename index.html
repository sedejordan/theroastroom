Theme

The button writes CSS custom properties onto the document root. Every theme property is cleared before the next theme is applied, so a coming soon club that only defines primary and accent falls back to the defaults for every other token.

Current theme: Manchester United

Club theme colours

Nine tokens, one CSS custom property each. The value shown under every swatch is read live from the document root.

  • Primary --colorPrimary #DA291C
  • Primary contrast --colorPrimaryContrast #FFFFFF
  • Accent --colorAccent #FBE122
  • Background --colorBackground #0A0A0A
  • Surface --colorSurface #141414
  • Surface raised --colorSurfaceRaised #1C1C1C
  • Line --colorLine #2A2A2A
  • Text --colorText #F5F5F5
  • Text muted --colorTextMuted #A0A0A0
